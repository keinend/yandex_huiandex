# Yandex Smart Home Control

Приложение для Windows, macOS и Linux для управления устройствами и сценариями Яндекс Умного дома.

[Скачать приложение](https://github.com/keinend/yandex_huiandex/releases/latest) · [Сообщить о проблеме](https://github.com/keinend/yandex_huiandex/issues)

## Возможности

- Переключение между домами, комнатами и группами устройств.
- Запуск сценариев и управление доступными функциями устройств.
- Настройка света: яркости, цвета и температуры.
- Настройка климатических устройств: температуры, режима и скорости вентилятора.
- Просмотр показаний датчиков и видеопотоков камер Яндекс.
- Избранные устройства и сценарии с быстрым доступом через системный трей.
- Обновление состояния устройств, проверка новых версий и автозапуск.
- Светлая и тёмная темы.

Доступные настройки зависят от возможностей конкретного устройства и API Яндекса. Устройства и сценарии нужно заранее добавить в приложение «Умный дом с Алисой».

## Установка

Откройте [страницу релизов](https://github.com/keinend/yandex_huiandex/releases) и скачайте сборку для своей системы:

- **Windows:** запустите установщик `.exe`.
- **macOS:** откройте `.dmg` и перенесите приложение в папку «Программы».
- **Linux:** используйте доступный пакет `.deb`, `.rpm` или файл `.AppImage`. Для AppImage разрешите выполнение файла в его свойствах.

После установки запустите Yandex Smart Home Control. Для подключения дома потребуется OAuth-токен Яндекса.

## Получение токена

1. Откройте [Яндекс OAuth](https://oauth.yandex.ru/client/new/) и создайте приложение для доступа к API или отладки.
2. В доступах к данным укажите `iot:view` и `iot:control`.
3. Скопируйте `ClientID` созданного приложения.
4. Подставьте его вместо `YOUR_CLIENT_ID` в адрес ниже и откройте адрес в браузере:

   ```text
   https://oauth.yandex.ru/authorize?response_type=token&client_id=YOUR_CLIENT_ID
   ```

5. Подтвердите доступ, скопируйте полученный токен и вставьте его на экране входа в приложение.

Описание API доступно в [официальной документации Яндекс Умного дома](https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-quickstart).

Для просмотра камер приложение дополнительно предложит авторизацию Яндекса по QR-коду. При истечении этой авторизации её потребуется пройти повторно.

## Хранение данных

OAuth-токен для управления домом и X-Token для камер хранятся в системном хранилище учётных данных через `keytar`:

| Запись | Назначение |
|---|---|
| `SmartHomeControlApp/YandexToken` | Управление устройствами и сценариями |
| `SmartHomeControlApp/YandexXToken` | Доступ к камерам |

Краткоживущий JWT видеопотока запрашивается при подключении к камере и не сохраняется в системном хранилище. Кнопка выхода из приложения удаляет оба сохранённых токена.

## Запуск из исходников

Потребуются Node.js 22, npm и Git.

```sh
git clone https://github.com/keinend/yandex_huiandex.git
cd yandex_huiandex
npm install
npx electron-builder install-app-deps
npm run electron-dev
```

Команда `electron-dev` запускает Vite и окно Electron.

### Проверки и сборка

```sh
npx vitest run
npm run build
npm run dist -- --publish never
```

Сборка интерфейса находится в `dist/`, установочные файлы — в `release/`. Установщик собирается для текущей операционной системы.
